## 🧱 项目结构

```
├── data/      # 存放原始文献数据
├── src/       # 数据处理与分析代码
├── outputs/   # 分析结果（图表、网络图等）
├── reports/   # 分析报告与过程说明
└── paper/     # 最终论文稿件
```
## 🛠️ 使用工具

-  CiteSpace —— 文献计量分析与可视化
-  VOSviewer —— 关键词共现与网络分析
-  Python —— 数据处理与统计分析

**常用 Python 库：**
- pandas
- numpy
- matplotlib

## 🚦 使用方法（可复现说明）

1. 📥 **获取数据**  
   将文献数据文件（CSV格式）放入 `data/` 文件夹。

2. 🧹 **数据处理**  
   运行 `src/` 目录中的 Python 脚本进行数据清洗与统计分析。

3. 📊 **可视化分析**  
   使用 CiteSpace 或 VOSviewer 进行分析，生成关键词网络图、趋势图等。

4. 💾 **输出结果**  
   所有分析结果保存在 `outputs/` 文件夹中。
