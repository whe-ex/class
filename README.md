# 人工智能领域文献计量分析项目

## 👥 小组成员
- 刘晋安
- 吴君豪
- 丛嘉孚
- 邓子聪

## 🎯 研究方向
本项目基于文献计量学（Bibliometrics）方法，对人工智能（Artificial Intelligence）领域的研究热点与发展趋势进行分析。  
通过对相关文献数据的统计与可视化分析，探索本领域的研究前沿、热点主题以及演化趋势。

## 📌 研究目标
- 分析人工智能领域近年的发文趋势
- 识别研究热点（关键词分析）
- 构建关键词共现网络
- 探索研究前沿与发展方向

## 📊 数据来源
项目数据主要来源于学术数据库（如 Web of Science / Google Scholar），通过关键词检索获得相关文献。

**示例检索关键词：**  
`"artificial intelligence" OR "machine learning" OR "deep learning"`

## 🧱 项目结构

```
├── data/      # 存放原始文献数据
├── src/       # 数据处理与分析代码
├── outputs/   # 分析结果（图表、网络图等）
├── reports/   # 分析报告与过程说明
└── paper/     # 最终论文稿件
```

## ⚙️ 使用工具

- CiteSpace —— 文献计量分析与可视化
- VOSviewer —— 关键词共现与网络分析
- Python —— 数据处理与统计分析

**常用 Python 库：**
- pandas
- numpy
- matplotlib

## 🚀 使用方法（可复现说明）

1. **获取数据**  
   将文献数据文件（CSV格式）放入 `data/` 文件夹。

2. **数据处理**  
   运行 `src/` 目录中的 Python 脚本进行数据清洗与统计分析。

3. **可视化分析**  
   使用 CiteSpace 或 VOSviewer 进行分析，生成关键词网络图、趋势图等。

4. **输出结果**  
   所有分析结果保存在 `outputs/` 文件夹中。
